## Design

Separate SQLite road database with bounded persistent tiles (.08 degrees latitude x .12 longitude; ~9 x 8 km near Merseyside). Select all tiles intersecting a 32,187 m circle, prioritising current and ahead-of-travel missing/stale tiles. Sequential bounded requests, no download barrier on Start. Keep valid older data indefinitely while retained; age triggers refresh after seven days, never automatic unknown. Coverage builds progressively; network/provider failure cannot guarantee all tiles completed at once.

Overpass source remains unchanged. Fetch only existing drivable roads and camera intelligence (no buildings, land use, imagery, POIs, recursive node downloads). Persist only matching speed/oneway/name/ref fields, geometry, way IDs and camera fields. Request final out count; reject remarks, truncated/missing geometry, duplicate IDs and count mismatches. Persist tiles and metadata in one SQLite transaction, activate only after commit. Empty tiles require a verified zero count. Migrate legacy snapshot as bounded partial coverage without pretending it is a complete tile.

Refresh planner checks every 15 minutes, or approaching an unfetched/stale tile, with 30-second minimum request spacing, exponential failure backoff up to 15 minutes. Same fresh stationary coverage does not redownload. Persistent daily budget <=90 requests, <=9 MB transfer to respect regular public-instance guidance; coverage is explicitly partial when constrained. Stop cancels all work. Full geometry parsing, database queries and matching off main thread. Spatial SQLite road bounding index; read only nearby candidate geometry, not all tiles per GPS fix. Retain useful most-recent public payloads within a 32 MB target plus database/index overhead /160 tiles, protecting immediate 3×3 tiles. On eviction, suppress missing outer-tile refills until moving 5 km, but still refresh retained stale tiles. Dense protected coverage may exceed the target temporarily. Corrections do not expire with public cache.

Decision priority: local direction-scoped road override, newest matching saved OSM row, older retained OSM row, unknown. Static unsupported tags remain unknown without owner override. Hysteresis: new known limit requires >=3 accurate samples over >=2 seconds and movement past connecting junction with GPS allowance. Same-limit continuation is seamless. Unknown roads do not inherit unrelated limits.

Too early appears for 30 seconds after a confirmed change. It reverts to previous known limit and stores pending transition evidence (road IDs, predicted position, bearing, accuracy, confidence/distance, time, source limits). Changed now completes a scoped boundary record using an accurate same-transition/direction fix within 2 km and 10 minutes. Pending expires; cancel supported. Future same directed transition holds old limit and previews new until GPS confidently crosses observed boundary plane; no exact-coordinate requirement. Bad/opposite/off-road inputs cannot apply it. Preserve source tags. Diagnostics offers parked override save/reset and learned-boundary reset.
