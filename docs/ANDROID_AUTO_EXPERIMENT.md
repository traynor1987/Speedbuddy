# Android Auto passive-surface experiment

This private prerelease experiment uses the Android for Cars App Library service/template path. The car service observes the existing in-process DriveBus only; Google Maps remains responsible for navigation.

0.2.6 added the required Android Auto application descriptor and template capability used for launcher discovery. No destination, route, active navigation session, second GPS collector, second driving service, second camera engine or second audio path is added.
